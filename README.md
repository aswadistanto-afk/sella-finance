# Sella Finance

Aplikasi pencatatan keuangan pribadi dan operasional berbasis web modern yang diintegrasikan langsung dengan **Google Apps Script** (GAS) dan **Google Sheets** sebagai database backend tanpa biaya server (*zero-cost infrastructure*).

## Fitur Utama
- **Dashboard Ringkasan Keuangan**: Visualisasi pemasukan, pengeluaran, saldo, dan alokasi anggaran secara real-time.
- **Pencatatan Transaksi Cepat**: Form input transaksi interaktif dengan kategori, nominal, dan tanggal otomatis.
- **Google Sheets as Database**: Data tersimpan aman di Google Drive dengan skema tabel terstruktur.
- **Responsive UI**: Tampilan modern, bersih, dan optimal untuk perangkat mobile maupun desktop.

## Teknologi
- **Frontend**: HTML5, Vanilla JavaScript, Tailwind CSS / Modern CSS.
- **Backend / API**: Google Apps Script (`HtmlService`, `SpreadsheetApp`).
- **Database**: Google Sheets.
